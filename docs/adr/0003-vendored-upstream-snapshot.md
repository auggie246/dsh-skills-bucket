# Vendored upstream snapshot over live pulls

The bundle ships Matt Pocock's skills as a vendored snapshot: `scripts/sync-upstream.mjs` pulls the pinned upstream release tag, applies the ask-user overlay patches from auggie246/dsh-mattpocock-skills, and flattens the chosen categories into `skills/`; the host registers the result as runtime skills (ADR-0002). The pin is a release tag, never a branch or a bare commit, so a rebuild of the same bundle version reproduces the same skills; `upstream.lock.json` records the tag, the resolved sha, and the patch ref for provenance. The rejected alternatives: downloading at host start (network in boot, non-hermetic, fails closed too late) and keeping the file-copy installer as a second source of truth (two copies that drift). Trade-offs: updates need a sync run plus a harness restart instead of the skill-filesystem watcher's live refresh; a tag pin can sit below unreleased `main`, so content lags upstream between releases, and moving the pin is one `--latest-tag` run plus a version bump. The overlay patches are re-based onto release tags, not `main`, so a tagged sync keeps every patched skill patched (8 patches had gone stale against v1.2.3 before the re-base).
